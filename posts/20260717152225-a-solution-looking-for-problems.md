title: A Solution Looking For Problems
tag: ai, notes
--

A long time ago, by chance, I read a debate between a crypto bro and a "conservative". The discussion talked around how "crypto" is irrelevant in Indonesia. As far as I understand, the "conservative" side talked about how in Indonesia, with the ease of payment using VA and now QRIS, crypto is not a necessary option, and just because a big country like America is very bullish about it doesn't mean it's the same context. The guy added that "crypto" is just a solution looking for problems. And you know what other thing looks like this, a solution looking for problems? AI Agents.

Let me be clear first, there's nothing wrong using AI agents like OpenClaw or Hermes, I tried OpenClaw, I tried Hermes, but to be honest sometimes it's fun to set up but I don't know what to do anymore with these tools.

First, I tried OpenClaw, set it up as an AI assistant so I could use it via Telegram chat, but after that I didn't know what to do anymore with this tool. I tried using it so I could ask my assistant to read logs? I could already open it in Grafana Loki, and again, most of my projects are used by me and my wife, so basically the debug session is just us talking to each other.

I look at my friends, they're using tools to write a blog, it's cool, the content is interesting, a lot of information I can learn, I think writing a blog is a way to make me still a human. Currently a lot of work I've already handed over to AI, I just work as a judge, it's either merge, release, rollback, and all the heavy lifting is already done by AI. When I write, I can choose my own persona, it's either I want to write like step by step, random rants, using proper language, using slang, and that's the fun of writing a blog, isn't it? Delegate that to AI? For now, no thank you.

> I still use AI to proofread but not for writing blogs.

## Fomo

No matter how much I try to defend myself, the information about the latest new cool things in tech is always available, and it's worse if you join a community with a lot of nerds -- I'm talking about the pegelLinux community by the way. In there, there are a lot of cool nerds with various up-to-date implementations of cool tech, first I tried to join the bandwagon, tried to keep up, and then I went on holiday, back to daily life, read the Telegram group again and I look like a caveman looking at fire for the first time. Don't get me wrong, they are cool nerds not the "nerd", but, for me, sometimes the best is just to keep using what actually works, it's good to know the latest tech but as long as my setup works, let me gradually apply it to my setup without any pressure.
